II. Background and Objectives

1. Project Background

In industrial assembly and warehouse sorting, traditional robots often require manual coordinate setting, which is cumbersome and lacks flexibility. Voice control, as a natural human-computer interaction (HCI) method, enables a fully automated “Voice Command → Automated Recognition → Precise Grasping” workflow, enhancing production efficiency while lowering the barrier for operators. This project focuses on “tool grasping” by integrating speech recognition (DTW), computer vision (YOLOv8/GRCNN), and robotics control to develop a lightweight, real-time, and controllable collaborative system for industrial environments, avoiding total reliance on “black-box” deep learning.

2. Core Objectives

  • Speech Recognition: Implement keyword recognition for 5 tool types (“Hammer, Wrench, Screwdriver, Pliers, Tape Measure”), achieving ≥90% accuracy for isolated words and ≥85% for keywords at the start of short phrases.
  • Object Recognition: Achieve a mAP50 of ≥93% using YOLOv8, ensuring robust detection across varied lighting and orientations in real-world lab settings.
  • Grasping Control: Generate effective grasp points with ≥90% accuracy via GRCNN and achieve a ≥85% hardware success rate for the UR robot. Implement adaptive gripper force (e.g., 40% for tape measures, 80% for metallic tools).
  • User Experience: Develop a visualization UI supporting one-click “Voice Input → Image Recognition → Execution” operations, accompanied by hardware demonstration videos.

III. Core Technical Implementation

Task 1: DTW-Based Speech Recognition Module

1. Algorithm Pipeline and Preprocessing

Adopted a three-step workflow—“Template Recording → Signal Preprocessing → DTW Matching”—to resolve temporal inconsistencies in speech signals:

  • Template Recording: Recorded 6 audio samples for each of the 5 keywords at different pitches and speeds (16,000Hz, Mono, 16-bit), generating 30 templates (Fig 1).
  • Signal Preprocessing:
    1. Applied framing (20ms length, 10ms shift) and pre-emphasis to boost high-frequency signals.
    2. Implemented dual-threshold Voice Activity Detection (VAD) to isolate speech from silence.
    3. Extracted 13-dimensional Mel-Frequency Cepstral Coefficients (MFCC) to transform audio into feature vectors (Fig 2).
  • DTW Matching: Real-time recording (2.5s duration, CHUNK=1024) is matched against templates by calculating Euclidean distance. The template with the minimum distance is selected as the result (e.g., “Hammer” distance ≈ 7585, Fig 3).

Task 2: Tool Recognition Based on YOLOv8

1. Model Development and Dataset Optimization

  • Model Selection: Selected YOLOv8 for its 12% precision improvement over YOLOv5 and robust community support, focusing on 5 tool categories.
  • Dataset Iteration:
    1. Initial Dataset: 200 images with salt-and-pepper noise and rotation augmentation; mAP50 reached 88%, but real-world miss rates were high.
    2. Optimized Dataset: Filtered out cartoonish/handheld images and supplemented with 300 lab-captured physical tool images. Adopted an “incremental training” strategy.
    3. Knowledge Distillation: Used YOLOv8-L as a teacher model to transfer features to the YOLOv8-N student model, enhancing generalization.
  • Final Results: The optimized model achieved a mAP50 of 95.2%, with detection precision for all tools exceeding 93% and miss rates dropping below 10% (Fig 4, 5).

Task 3: GRCNN Grasp Planning and Robot Control

1. Planar Grasp Point Generation (GRCNN)

  • Logic: Fused RGB+Depth information from an Intel RealSense camera. GRCNN generates a global grasp confidence map, which is then cropped based on YOLOv8 bounding boxes to extract optimal grasp parameters (position, angle, width):
    1. Image Preprocessing: Cropped YOLOv8 regions (confidence ≥ 0.5) with a 20px padding to ensure tool integrity.
    2. Parameter Generation: Output grasp quality (q_img), angle (ang_img), and width (width_img) maps, locating local maxima for the grasp point (Fig 7).
    3. Optimization: Increased depth weighting for flat tools (e.g., wrenches) to eliminate invalid grasp candidates.

2. Coordinate Transformation and UR Control

  • Mapping:
    1. Pixel to Camera: Used RealSense intrinsics ($f_x, f_y, c_x, c_y$) and depth $Z$ to calculate 3D camera coordinates (Fig 8).
    2. Camera to Robot: Calibrated via a 5×5 checkerboard (24 points) to compute the hand-eye transformation matrix $T$.
  • UR Control:
    • Utilized the ur-rtde library for TCP/IP communication. Implemented move_L/move_J for linear/joint motion (velocity = 0.2m/s, acceleration = 0.1m/s², tolerance 2mm).
  • Gripper Control:
    • Used MinimalModbus via serial communication. Implemented adaptive force control: 80% for metallic tools (Hammer/Wrench) and 40% for plastic tools (Tape Measure) to prevent damage.
