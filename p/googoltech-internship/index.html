II. Background Analysis

1. Industry Context

With the “Made in China 2025” strategy, the manufacturing sector is accelerating toward digitalization and intelligent transformation. Motion control technology, serving as the “brain and nervous system” of industrial automation, is widely applied in robotics, CNC machine tools, and semiconductor equipment. However, high-end markets have long been dominated by foreign vendors. Achieving self-controllability and domestic substitution in this field is critical for securing supply chains and enhancing the competitiveness of high-end equipment.

2. Company Profile

Founded in 1999 by Professors Zexiang Li, Bingqiang Gao, and Hong Wu from HKUST, Googoltech is a pioneer and platform leader in China’s motion control industry. As a national high-tech enterprise, the company focuses on R&D in motion control, servo drives, machine vision, and industrial networking, becoming the preferred domestic brand for core control components in high-end equipment.

3. Project Context

To address the talent gap and the disconnect between theory and practice in high-end equipment manufacturing, Googoltech established “Googol Park.” Utilizing a Project-Based Learning (PBL) model with real-world industrial projects, it provides an “Imitation-Assimilation-Optimization-Excellence” learning path. This project, based in Googol Park, involved a one-month immersive practice in the full-cycle development of an electromechanical system.

4. Technical Architecture

The project is built on Googoltech’s proprietary technical ecosystem:

  • Motion Controller: Executes complex path planning and multi-axis coordination algorithms.
  • Servo Drive: Receives commands and drives motors with high precision.
  • Industrial Fieldbus (gLink-II): Provides high-speed stable communication with 100ns synchronization precision and data redundancy.
  • Toolchain: OtoStudio IDE (ST language), Janus (visual low-code), and DriverStudio (servo tuning).

III. Task Overview

1. Project Introduction

The objective was to independently complete the electromechanical integration, process design, and tuning of a PCB 3-axis drilling machine. The device uses X, Y, and Z-axis precision motion for positioning and drilling, serving as a typical industrial carrier for understanding motion control applications.

2. Core Tasks and Requirements

  1. Mechanical Awareness: Analyze the 3-axis modules, motors, and drilling actuators to understand motion principles and load characteristics.
  2. Electrical Integration: Design electrical schematics and connect controllers, drives, motors, and sensors to build the hardware system.
  3. Signal Logic Analysis: Define X/Y/Z control signals (Enable, Alarm, Position) and IO signals (Limits, Origin, Drill Start).
  4. Process Design: Define the sequence from “Standby → Homing → Precise Positioning → Drilling → Loop/End,” incorporating safety protections (E-stop, Overtravel).
  5. Multi-mode Control Implementation:
    • Low-code: Rapid logic implementation using Janus visual blocks.
    • Structured Text (ST): Detailed low-level logic development via OtoStudio.

3. Expected Outcomes

  • Physical Prototype: A fully commissioned 3-axis motion control device executing precise autonomous drilling.
  • Internship Report: Summary of design, integration, and tuning, including technical solutions and troubleshooting.
  • Certification: Completion of Googol Park assessment and acquisition of the “Electromechanical System Integrated Application Technology” certificate.

IV. Technical Route and Solutions

Task 1: Systematic Training on Googoltech Products

1. Core Knowledge System

  • Product Architecture: Understanding the logic from controllers (Plug-in/Embedded) to integrated drive-control units (Nayun/GTSD) and software platforms.
  • Technical Principles: gLink-II gigabit ring network (100ns precision); core algorithms like PSO (Position Synchronized Output for 2μm interval drilling) and 5-axis RTCP.

2. Toolchain Proficiency

  • OtoStudio: Developed low-level motion logic (e.g., homing sequences) using ST language.
  • Janus: Designed process flows (e.g., automatic drilling cycles) via graphical blocks.
  • DriverStudio: Performed servo parameter auto-tuning (vibration suppression, gain adjustment).

Task 2: Electromechanical Characteristic Matching

1. Core Matching Principles

  • Power Matching: Drive system max power $\geq$ 1.5–2x peak load power to prevent motor overload.
  • Inertia Matching: Load-to-rotor inertia ratio $\leq$ 3 (Precision $\leq$ 1) to prevent low-frequency oscillation.
  • Speed & Precision: Motor rated speed $\geq$ load max speed $\times$ gear ratio; encoder resolution must be 3x better than target precision.

2. Calculation Logic

  • Equivalent Inertia: $J_{eq} = J_{load} + (J_{rotor} / n^2)$
  • Torque Demand: $T_{peak} = J_{eq} \cdot \alpha_{max} + T_{friction}$

1. Tools and Objectives

  • Tool: DriverStudio software for monitoring Current (Id/Idr), Velocity (Vel), and Position Error (Perr) curves.

PROGRAM AxisControl
VAR
  Axis1: MC_AXIS_REF;          // Axis reference
  Position: LREAL := 500.0;    // Target position (mm)
  Velocity: LREAL := 100.0;    // Velocity (mm/s)
  Start_Sig: BOOL := FALSE;    // DI Start Signal
  Done_Sig: BOOL := FALSE;     // DO Done Signal
END_VAR

// Enable and Home
IF Start_Sig AND NOT Axis1.Status.Enabled THEN
  MC_Enable(Axis1);           
  MC_Home(Axis1, TRUE);       
END_IF

// Absolute Move
IF Axis1.Status.Homed AND NOT Done_Sig THEN
  MC_MoveAbsolute(Axis1, Position, Velocity, 500.0, 500.0, FALSE);
  IF Axis1.Status.OperationComplete THEN
    Done_Sig := TRUE;         
  END_IF
END_IF
