III. Project Abstract

Based on the requirements of Problem H, we developed an autonomous driving vehicle centered around the TI MSPM0 Series MCU. The core constraints and objectives are as follows:

  • Hardware Constraints: Vehicle dimensions ≤ 25cm (L) × 15cm (W) × 15cm (H); exclusively utilizes the TI MSPM0 Series MCU; no cameras allowed.
  • Site Constraints: 220cm × 120cm white matte field with a 1.8cm wide black semi-circular path (radius 40cm, featuring points A/B/C/D).
  • Achievements: Successfully completed all 4 mandatory tasks, with Task 4 (continuous driving) optimized to 78 seconds.

IV. System Architecture

1. Hardware Architecture

Module Category Selected Components Functional Role (Requirements Mapping)
Main Controller TI MSPM0G3507 (16-bit, 80MHz) Task scheduling, path calculation, and PID control (Mandatory per Problem H Note 1).
Path Recognition 8-way IR Line-tracking Sensors Detects the black path and calculates lateral error (Black arc path detection).
Attitude Sensing ICM-20602 9-axis IMU Captures Roll/Pitch/Yaw to prevent tail-flicking during high-speed arc turns.
Speed/Positioning Hall Encoders (100 pulses/rev) Measures motor RPM and travel distance for precise parking.
Motor Driver TB6612FNG Module Drives DC motors with PWM-based speed regulation for dynamic path transitions.
HMI 0.96-inch OLED + 3-way Buttons Displays task modes/parameters and supports manual task switching.
Power Supply 11.1V Lithium Battery (2200mAh) Ensures ≥1 hour of runtime for multiple testing rounds (Problem H Note 6).

2. Software Architecture (Timing and Logic)

(1) Core Control Framework: “Main Loop State Machine + Timer Interrupt” Synergy

The software architecture is built on the principle of separating non-real-time tasks (Main Loop) from real-time tasks (Timer Interrupts). This ensures high timing precision for Problem H tasks (e.g., path error detection and PID cycles):

  • Module 1: Main Loop State Machine (Non-real-time Global Scheduling) Acts as the central dispatcher for initialization, task switching, and status display:

    1. Initialization: Configures hardware for sensors (IR, Encoders), motor drivers, and the OLED display.
    2. Task Mode Selection: Supports manual/automatic switching between Tasks 1–4, loading specific path parameters and control logic for each.
    3. Status Monitoring: Outputs real-time telemetry to the OLED for debugging and performance verification.

  • Module 2: Timer Interrupts (Precision Real-time Task Execution) Utilizes a combination of hardware timer interrupts (mid-low frequency) and external pin interrupts (high frequency) to prevent main loop blocking and ensure timing accuracy:

    1. Encoder Data Acquisition (1ms): Triggered via external pin interrupts on encoder phases (Rising/Falling edges) for real-time distance and speed calculation.
    2. PID Control Calculation (5ms): Powered by TIMER_0 (10ms hardware interrupt) with software subdivision (executes every 2 interrupts). Dynamically adjusts motor speed and steering based on encoder feedback and IR path error.
    3. IR Sensor Acquisition (10ms): Directly triggered by TIMER_0 (10ms hardware interrupt) to sample path signals (e.g., “Left Deviation,” “Centered”) for PID input.

(2) Task Logic and Control Strategy Mapping

Task No. Functionality (Problem H) Core Control Strategy Module Dependency
Task 1 A→B Auto Drive + Parking Basic line-tracking (IR error correction) + Pre-deceleration logic (speed reduction near Point B for parking accuracy). Main Loop (Task Switch) + Timer (PID Control)
Task 2 A→B→C→D→A Full Path Pose fusion (Encoder distance + IR deviation) + Audio-visual alerts at waypoints (B/C/D). Main Loop (Status) + Timer (Data Acq)
Task 3 A→C→B→D→A Complex Path Path node pre-storage (recording waypoint coordinates) + Steering timing control (pre-calculating turn angles before reaching nodes). Main Loop (Parameters) + Timer (PID Steering)
Task 4 4-Lap Continuous Driving Voltage compensation (preventing RPM drift as battery levels drop) + Iterative optimization (fine-tuning path error parameters per lap). Main Loop (Monitoring) + Timer (High-freq PID)
