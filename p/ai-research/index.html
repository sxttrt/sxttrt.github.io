II. Background and Objectives

1. Project Background

While Deep Learning excels in large-scale complex tasks, it often suffers from parameter redundancy, poor interpretability, and high computational demands. Traditional machine learning algorithms (e.g., K-means, PCA, Logistic Regression) remain highly valuable in small-to-medium data scenarios due to their mathematical transparency, lightweight nature, and reproducibility.

This project focuses on “Exploring the performance boundaries and hyperparameter influence of traditional algorithms,” targeting two typical domains:

  • Classification Tasks: Including clustering of the “Seeds Dataset” (K-means/Soft K-means) and binary classification of “X-shaped Distribution Data” (Logistic Regression/MLP).
  • Image Processing Tasks: Implementing image reconstruction based on PCA, Linear Autoencoders, and Soft K-means to explore the correlation between “latent dimensions/clusters” and “reconstruction quality.”

All algorithms were implemented from scratch using pure Python/NumPy without relying on third-party ML libraries, aiming to deeply understand the underlying logic and summarize reusable parameter tuning patterns.

2. Core Objectives

  • Clustering Exploration: Analyze the impact of “cluster count, split-merge strategies, iterations, and tolerance” on the Seeds dataset. Compare accuracy stability and resistance to local optima between K-means and Soft K-means.
  • Image Reconstruction: Use an image of a WWI soldier to explore how “retained dimensions” (PCA/AE) and “cluster count” (Soft K-means) affect color restoration and detail retention.
  • Binary Classification: Compare the fitting capabilities of linear (Logistic Regression) vs. non-linear (MLP) models on X-shaped data. Focus on how MLP “hidden layers, neurons, and tolerance” affect convergence speed and accuracy.
  • Engineering Excellence: Modularize algorithm components and provide visualization scripts (accuracy curves, reconstruction comparisons) to ensure experiment reproducibility and intuitive interpretation.

III. Core Technical Implementation

Task 1: K-means & Soft K-means Clustering (Seeds Dataset)

1. Algorithmic Design

This task explores the impact of algorithm type and hyperparameters (K, split-merge, iterations, tolerance) on clustering accuracy:

  • K-means Design:
    • Core Logic: Minimizing the Within-Cluster Sum of Squares (WCSS): $$J=\sum_{i=1}^{k} \sum_{x \in C_{i}}\left| x-\mu_{i}\right| ^{2}$$
    • Optimization: Designed a dynamic “Split-Merge” scheme (splitting the cluster with max distance + merging the two closest clusters) to improve stability without exploding the cluster count.
  • Soft K-means Design:
    • Core Logic: Introduced probabilistic weights $w_{ij}$ (probability of $x_i$ belonging to cluster $j$): $$J=\sum_{i=1}^{n} \sum_{j=1}^{k} w_{ij}\left| x_{i}-\mu_{j}\right| ^{2}$$
    • Optimization: Implemented “K-means++” style initialization (probabilistic distance-based centroid selection) to contrast with K-means random initialization.

2. Experimental Analysis

Based on the Seeds dataset (3 classes, 210 samples), we analyzed the impact of core parameters:

Tolerance Impact (k=3, No Split-Merge): In the range of $1e-3$ to $1e-5$, accuracy remained constant, indicating low sensitivity. Fixed at $1e-5$ for subsequent tests.

Iteration Impact (k=3, Tolerance=1e-5):

  • K-means: Peak accuracy (89.05%) at 200 iterations; accuracy declined beyond 200 (possible over-fitting).
  • Soft K-means: Accuracy stabilized at 89.52% after only 50 iterations, demonstrating superior convergence stability.

Cluster Count & Split-Merge (Iter=200, Tol=1e-5):

  • Cluster Count: Increasing $k$ from 3 to 10 caused K-means accuracy to drop by 3%, while Soft K-means improved by 0.48%, showing better adaptability to high-cluster scenarios.
  • Split-Merge: Enabled strategies slightly hindered performance for the Seeds dataset due to its compact distribution.

Task 2: Image Reconstruction (PCA, Linear AE, Soft K-means)

1. Technical Implementation

Focused on how dimensionality/clusters affect reconstruction quality for a 256×256 WWI soldier image:

  • PCA (Latent Dimension Exploration):
    • Computed the covariance matrix and performed SVD decomposition: $$C=U \sum V^{T}$$
    • Projected onto the top $k$ principal components ($k=1/2/3$).
  • Linear Autoencoder (Encoding Dimension Exploration):
    • Architecture: Input Layer $\rightarrow$ Encoding ($E=X \cdot W_e$) $\rightarrow$ Decoding ($D=E \cdot W_d$) (pure linear transformation).
    • Training: Used MSE loss and gradient clipping to prevent explosion.
  • Soft K-means (Cluster Count Exploration):
    • Treated pixels as samples and replaced original pixels with cluster centroids (explored $k=1/3/5/7/9$).

2. Results and Analysis

PCA vs. Linear Autoencoder:

  • Dim=1: Both outputted grayscale images. AE reconstruction error (0.015) was lower than PCA (0.018).
  • Dim=2: AE showed significant color restoration (error 0.008), while PCA remained dull (error 0.012), indicating AE’s superior linear feature retention.
  • Dim=3: Both achieved perfect reconstruction (zero error) as they fully captured the RGB channels.

Soft K-means Results:

  • At $k \leq 5$, significant color banding and detail loss (e.g., fabric texture) occurred.
  • At $k=9$, the model successfully recovered major colors and edge details (cap, collar), matching the image’s inherent color complexity.

Task 3: Logistic Regression vs. MLP (X-shaped Data)

1. Algorithmic Design

Focused on the impact of model type and MLP hyperparameters on non-linear decision boundaries:

  • Logistic Regression (Linear Baseline): Using Sigmoid activation $\sigma(z)$ and Cross-Entropy loss. Explored the limitations of linear models on intersecting data distributions.
  • MLP (Non-linear Exploration):
    • Architecture: Input (2D) $\rightarrow$ Hidden Layers (1-6) $\rightarrow$ Sigmoid Output.
    • Hyperparameters: Explored hidden layers, neurons per layer (2/4/8/20), and tolerance ($1e-5$ to $1e-8$).

2. Results and Analysis

Linear vs. Non-linear Comparison:

  • Logistic Regression: Failed to fit the X-distribution, topping out at 59.60% accuracy.
  • MLP (1 hidden layer, 8 neurons): Achieved 100% accuracy within 8,320 iterations.

MLP Hyperparameter Sensitivity:

  • Network Depth: 1-2 hidden layers with $\geq 8$ neurons were optimal. Increasing to 6 layers caused the model to trap in local optima (accuracy dropped to 77%).
  • Tolerance: $1e-7$ was the “sweet spot.” Tolerance $\geq 1e-6$ resulted under-fitting (accuracy $\approx 55%$), while $1e-8$ caused slight over-fitting and excessive computation.

2. Core Research Outcomes (Summary Table)

Domain Key Findings
Clustering Soft K-means is more stable (accuracy fluctuation $\leq 0.5%$) and performs better in multi-cluster scenarios ($k=10$) than K-means.
Reconstruction Linear AE outperforms PCA at lower dimensions (Dim=2) for color retention. Soft K-means require $k \geq 9$ for acceptable detail in low-color-complexity images.
Classification MLP with 1-2 hidden layers is optimal for non-linear boundaries; excessive depth ($\geq 6$ layers) significantly increases the risk of local optima entrapment.
